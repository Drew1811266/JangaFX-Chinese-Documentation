Expressions#

JangaFX software has the option to add expressions and use math in most places where you can type. For example, when you click on a parameter value.

This is especcially useful in the curveExpressions section.

The following is a comprehensive list on all available options.

Operators#

  • Add: +

  • Sub: -

  • Mul: *

  • Quo: /

  • Rem: %

  • Pow: ^

  • Open_Paren: (

  • Close_Paren: )

  • Comma: ,

Constants#

  • pi, Pi, PI, π

  • tau, Tau, TAU, τ

  • phi, Phi, PHI, φ, ϕ

  • e, E
