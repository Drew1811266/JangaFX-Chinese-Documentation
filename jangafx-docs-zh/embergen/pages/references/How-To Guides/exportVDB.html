VDB 导出#

如果想在其他软件中渲染模拟，可以将其导出为 VDB。

这种格式可以被 Maya 或 Blender 等其他软件读取。

在 EmberGen 中，VDB 使用 Export: VDB 节点导出。

此节点可以连接到 Volume（体积）节点的 VDB 输出引脚。

这意味着在 Volume Processing（体积处理） 节点中对体积做出的所有更改，例如锐化或 Post Modulation，都会包含在 VDB 文件中。着色和灯光等在后续阶段计算的其他内容不会存储在 VDB 文件中。

“Transform”输入引脚可以连接到 Transform 输出引脚，该输出引脚位于 Import 节点上。这会将 Import 节点上的反向变换应用到 VDB 网格。当你想在导出导入网格的应用程序中对齐 VDB 时，这会很有用。

Export: VDB 节点：#

  • 在 Export 选项卡中，可以设置文件名和位置，使用 Directory 参数。

  • 要指定导出范围，可以使用 First Frame 和 Num Frames 参数。例如，如果要导出第 230 帧到第 450 帧，请将 First Frame 设为 230，并将 Num Frames 设为 220（450-230）。

  • “Export: VDB”节点也会显示在时间轴编辑器（Timeline Editor（时间轴编辑器））中，你可以通过蓝色条直观看到时间轴中的哪一部分会被导出。

  • 在 Controls（控制）选项卡中，可以指定要导出的通道。默认情况下只勾选 Density（密度）和 Flames（火焰），因为这两个通道通常足以渲染效果。

  • Coordinate System 用于指定要导出到的 3D 软件包的坐标系。例如，使用 Blender 时应保持为 Z Up Right Handed，使用 Maya 时应设置为 Y Up Right Handed。

  • Length Unit 用于指定要导出到的 3D 软件包所使用的长度单位。

  • 使用 Export Now 按钮将模拟导出为 VDB！

  • 可以选择多个 Export VDB 节点并单击 Export All（位于右键菜单中），一次从多个 Export VDB 节点导出。

着色器设置#

在 Maya 中使用 aiStandardVolume 或在 Blender 中使用 Principled Volume（Principled 体积着色器）时，需要将 Temperature Attribute 改为 flames

Colored Smoke#

使用 Colored Smoke 模拟模式时，Temperature（温度）、Fuel（燃料）和 Flames（火焰）通道会存储 Red（红）、Green（绿）、Blue（蓝）信息！
