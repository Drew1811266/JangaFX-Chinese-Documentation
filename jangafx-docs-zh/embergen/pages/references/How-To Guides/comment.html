注释#

注释可用于整理节点图，并为一组节点添加有用的说明。

若要创建注释，请按 C 或 Ctrl + G

你也可以 右键单击一个或多个节点，然后选择 Create Comment（位于上下文菜单）。

选中一个或多个节点时，注释会贴合所选节点的范围。

没有选中节点时，可以在节点图中绘制注释，以指定它的大小和位置。

创建注释后会出现文本输入字段，你可以在这里设置注释文本。输入完成后，可以按 Enter ，或点击文本字段旁边的蓝色对勾按钮来设置注释文本。

若要在节点图中移动注释，请将光标放到注释标题上，然后使用 并拖动。

若要调整注释大小，请将光标放到注释的某个角上，然后使用 并拖动。

使用 操作注释标题时，会弹出包含以下选项的上下文菜单。

  • Set Comment Text: 也可以通过双击 注释标题来完成。

  • Select Content: 这会选择注释框内的所有节点。注意：只有完全位于注释框内的节点，才会被视为该注释的内容。

  • Set Color: 将光标悬停在此选项上时，右侧会出现一个色板。你可以 点击希望该注释使用的颜色。

  • Tidy Up: 这会让注释重新贴合其内容。选中节点时，它也会尝试将这些节点整齐对齐。

  • Delete: 删除注释。如果这些节点没有被选中，这不会删除注释中的所有内容。注意：这是节点图的常规删除命令，因此也会删除所有已选节点。
