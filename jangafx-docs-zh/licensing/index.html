浮动许可证指南#

JangaFX 浮动服务器#

重要

本指南适用于 EmberGen 1.2.7 及以上版本、LiquiGen 1.0.6 及以上版本、GeoGen 0.5.4-beta 及以上版本，以及 IlluGen 1.1.2 及以上版本。

如果你运行的版本低于上述任一版本，请参阅 旧版浮动服务器

概览#

浮动许可证服务器是一个程序，可向运行 JangaFX 产品的客户端发放租约。租约是在用户会话期间取得的许可证，直到用户手动释放租约为止。浮动服务器需要使用浮动许可证激活，该许可证允许服务器发放指定数量的租约。

启动服务器#

服务器是命令行程序，需要通过一些参数进行配置。在 Windows 上，你可以使用 Windows 命令提示符 cmd；在 Linux 上，基本可以使用任何 shell 程序，例如 bash。

在下文中，尖括号 <...> 内的内容是占位符，方括号 [...] 内的内容是可选项，可以省略。连续三个点 ... 表示某个参数可以使用多次。圆括号 () 用于分组，并不是命令的一部分。

例如，给定 --port <port_number>[:<lease_limit>]...，以下写法都是有效的：

  • --port 3942

  • --port 3942:7

  • --port 3942 --port 2493:2

该程序可以通过几种不同方式启动：

  • jfs <OPTIONS>（见 选项）

    使用下一节中描述的选项启动服务器。

  • jfs deactivate --product <name>

    停用指定产品。

  • jfs gen-activation --product <name>:<key> <path>

    用于离线激活和停用。这允许浮动服务器在没有互联网连接的机器上运行。 gen-activation 命令会在指定的 <path> 位置生成一个“激活文件”。该文件可以上传到此处，以获取“激活响应”。随后在运行服务器进行激活时，可以在 --activation-file 选项中使用该响应文件的路径。

  • jfs gen-deactivation --product <name>:<key> <path>

    生成一个“停用文件”，可将其上传到此处。这种情况下没有响应文件，上传后服务器会立即停用。

  • jfs service <SERVICE_COMMAND>（见 作为 Windows 服务运行）

选项#

至少需要一个 --product 或 --activation-file 选项。其他所有选项都是可选的。

选项

说明

--host <ipv4_address>

要监听的 IPv4 地址。（默认：0.0.0.0）此选项可以使用多次，以绑定到多个网络接口。

--port <port_number>[:<lease_limit>]

要监听的 UDP 端口。（默认：3942）可以选择指定此端口上发放租约数量的限制。此选项可以使用多次，以监听多个端口，并为每个端口设置可能不同的租约限制。

--max-connections <n>

服务器的最大连接数。（默认：2047）

--product <name>:<key>

要激活的产品名称和许可证密钥，中间用冒号分隔。以下产品名称有效：

  • suite

  • illugen

  • embergen

  • liquigen

  • geogen

  • vectoraygen

此选项可以使用多次，以激活多个产品并为其发放租约。

--activation-file <path>:<key>

从 license0.jangafx.com/activate 上传激活请求后获得的激活文件路径。许可证密钥与路径之间用冒号分隔。此选项可以使用多次，以激活多个产品并为其发放租约。

--log-file <path>

服务器记录日志消息的文件路径。如果省略，服务器会写入标准输出；但在 Windows 上作为服务运行时，默认日志文件为 log.txt，位于可执行文件所在的同一目录。

作为 Windows 服务运行#

在 Windows 上，许可证服务器可以作为名为 jangafx-floating-license-server 的 Windows 服务在后台运行。 service 子命令用于管理此服务。作为服务运行时，可以使用日志文件查看服务器活动。默认情况下，该文件名为 log.txt，位于可执行文件所在的同一目录。

  • jfs service install <OPTIONS>（见 选项）

    此命令会安装服务，并使用提供的选项运行。这些选项与直接运行服务器时使用的选项相同。已安装的服务会期望可执行文件仍位于安装时的同一路径。如果你将可执行文件移动到其他目录，需要先卸载再重新安装服务，以更新其路径。该服务会被配置为随系统启动运行。

  • jfs service uninstall

    卸载服务。如果你想更改安装服务时使用的选项，必须先卸载现有服务。

  • jfs service start

    在后台启动已安装的服务。

  • jfs service stop

    停止已安装的服务。

  • jfs service status

    检查服务是否正在运行。

客户端快速入门指南#

提示

要在软件中打开 License Manager，请导航到 Help > License Manager

  • 该 License Manager 允许连接/断开许可证服务器，并按需获取/释放租约

  • 使用 License Manager

    • 在你的许可证类型对应的选项卡下输入服务器详情，并连接到服务器

    • 连接到服务器后，可以安全关闭 License Manager 选项卡

    • 连接到服务器后，软件会自动获取租约

    • 软件退出时会自动释放租约

    • 你可以从 License Manager 手动获取和释放租约

  • 使用环境变量
    • 使用相应名称和服务器详情创建环境变量
      • 名称根据你的产品密钥而定：

        • Suite： JANGAFX_SUITE_SERVER

        • EmberGen： JANGAFX_EMBERGEN_SERVER

        • LiquiGen： JANGAFX_LIQUIGEN_SERVER

        • IlluGen： JANGAFX_ILLUGEN_SERVER

        • GeoGen： JANGAFX_GEOGEN_SERVER

      • 值： XXX.XXX.XXX.XXX:YYYY 或 example.com:12345

      • 如果设置了环境变量，软件会自动获取租约

      • 软件退出时会自动释放租约

  • 其他租约信息：

    • 如果租约因崩溃或与服务器断开连接而未释放，同一台机器在重新连接后可以重新获取并延长该租约

    • 如果租约因崩溃或与服务器断开连接而未释放，在租约时间结束前，其他任何人都无法使用该租约

    • 租约不能“借出”（即不能离线使用或长时间占用）

快速入门指南#

  • 激活： TurboFloatServer.exe -a="<your key here>"

    • 在线激活使用端口 80（HTTP）或端口 443（HTTPS）

    • 如需离线激活，请参阅下方“离线激活”

  • 停用： TurboFloatServer.exe -deact

  • 启动： TurboFloatServer.exe -x

    • 这会运行服务器，但不会安装服务。

  • 安装： TurboFloatServer.exe -i

    • 这也会启动 Windows 服务，服务名称为 TurboFloatServer-5260、TurboFloatServer-6575，或 TurboFloatServer-6576

    • 这需要管理员权限

  • 卸载： TurboFloatServer.exe -u

    • 可能需要管理员权限

  • 配置： TurboFloatServer-config.xml

    • 连接端口、线程数、租约时长、日志、宽限期和代理

    • 服务器会在配置的端口上监听租约请求（默认端口 13）

离线激活#

如果你需要离线激活，请通过 support@jangafx.com 联系我们，并按照以下步骤操作。

离线激活分为两步。你需要发送激活请求并接收响应：

  1. 生成激活请求

    • 传入产品密钥以及激活请求 XML 文件的位置

    • TurboFloatServer.exe -a="ABCD-EFGH-IJKL-MNOP-QRST-UVWX" -areq="C:\Location\To\Save\ActivationRequest.xml"

  2. 使用激活响应：将激活请求提交给我们并收到激活响应后，可以激活 TurboFloat Server： TurboFloatServer.exe -a -aresp="C:\Location\To\ActivationResponse.xml"

日志#

  • 关于连接和租约的详细日志会写入 tfs-log.txt 文件

  • 使用 -x 标志运行服务器时，这些消息会直接显示在控制台中

  • 你可以使用 TurboFloatServer-config.xml 配置文件来配置日志级别

    • notification： 记录租约创建、移除、过期以及其他非必要但可能有用的信息。此级别还包含所有其他级别输出（warning、error）。

    • warning： 记录配置错误或其他需要修复的问题。此级别还包含下一级输出（error）。

    • error： 记录 TurboFloat Server 未能完成其必须执行的操作，例如无法加载配置数据、无法处理数据等。

    • none： 不会写入日志文件

故障排查#

有关详细信息以及其他平台的说明，请访问 https://wyday.com/limelm/help/turbofloat-server

如果以下信息无法解决你的问题，并且你需要进一步支持，请联系 support@jangafx.com

软件无法获取或维持活动租约#

如果 License Manager（许可证管理器）已连接到许可证服务器，但 License Manager（许可证管理器）中的租约状态与软件中的状态不匹配，你需要同时关闭软件和 License Manager（许可证管理器）。随后重新打开软件以获取租约。

另外，如果你正在尝试使用 License Manager 连接服务器，请确保不存在前文档中所述名称的环境变量。

连接许可证服务器时出错#

某些网络可能配置为阻止端口 13。如果你在连接许可证服务器时遇到问题，请尝试将此端口改为服务器上允许的其他端口。

使用不同路径#

  • TurboFloatServer.exe 会假定 TurboActivate.dat 和 TurboFloatServer-config.xml 与服务器可执行文件位于同一位置

  • 使用 -pdets 和 -config 传入自定义路径：

    • TurboFloatServer.exe -a="Your Key" -pdets="YourTurboActivate.dat" -config="Config.xml"

服务器卸载失败#

如果出现错误消息： * Failed to remove this service from the Windows Firewall. 0x80070057

请尝试在 Windows Defender 中手动删除防火墙规则，然后再次尝试卸载。

这些规则将命名为： <software> 1.x floating license server，其中 <software> 可以是 EmberGen, LiquiGen, IlluGen 或 GeoGen。
