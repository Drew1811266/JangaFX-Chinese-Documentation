用户界面#

本页会说明用户界面的各个方面。

菜单栏#

  1. 打开或关闭项目管理器。

  2. File：

    • New Project Ctrl + N：离开当前项目，并从默认预设开始。如果当前项目有未保存的更改，会弹出提示询问是否保存。

    • Open Project Ctrl + O：打开文件浏览器，以便选择要打开的 .liquigen 文件。

    • Recent Projects： Ctrl + Shift + P 将鼠标悬停在此菜单项上时，会在右侧打开一个菜单，可从中选择最近打开的项目。

    • Save Ctrl + S：保存项目以更新 .liquigen 文件

    • Save As… Ctrl + Shift + S：打开文件浏览器，可在其中定义项目的文件路径和文件名。

    • Increment and Save Alt + Shift + S ：在项目文件旁边保存当前项目文件的递增副本。例如，如果当前正在处理 myProject1.liquigen，项目会被保存为 myProject2.liquigen，并放在与 myProject1.liquigen 相同的文件夹中；你会自动继续在 myProject2.liquigen文件中工作。请注意，项目是在递增之后保存的。如果项目名不是以数字结尾，第一次递增时会添加 _2。

    • Import… Ctrl + Shift + I：打开文件浏览器，以便查找要导入项目的 .fbx、.obj，或 .abc 文件。节点图中会使用指定资产创建一个 Import 节点。

    • Export…： 立即导出项目中的所有 Export 节点。

    • Export Variations…： 打开 Export Variations 窗口，用于导出多个独特元素。关于这一点的更多信息，请查看我们的 随机化 页面。

    • Quit Ctrl + Q：关闭 LiquiGen

  3. Edit：

    • Undo Ctrl + Z：撤销操作。

      这可以包括各种操作，例如更改参数或创建节点。

    • Redo Ctrl + Y 或 Ctrl + Shift + Z：重做操作。

    • Delete Delete 或 Backspace：可以删除、剪切、复制和粘贴节点或关键帧等内容。

    • Cut Ctrl + X

    • Copy Ctrl + C

    • Paste Ctrl + V

  4. Simulation：

    • Hard Reset Ctrl + R：从头重新开始模拟。

    • Reset R：从循环边界的开头重新开始模拟；如果没有循环边界，则从时间轴开头重新开始。

    • Step Once Z：将模拟向前推进一帧。

    • Pause Space：播放或暂停模拟。

  5. 设置:

    • Project Settings

    • Preferences

  6. Account：

    • Login…： 打开登录窗口，可使用电子邮件地址和密码登录 JangaFX 帐户。

登录后， Account 下拉菜单中会出现以下选项：

  • My Account：前往我们的在线帐户平台，可在那里管理订阅和账单。

  • My Plans…： 显示当前有效的计划。

  • Logout…： 退出 JangaFX 帐户。只要有有效许可证，仍然可以使用软件。

  1. Help：

    • JangaFX.com…：前往 JangaFX 网站，可查看产品、预设市场、定价页面等内容！

    • License Manager： 打开 License Manager 窗口。更多信息请查看我们的 许可 部分。

    • Release Notes…： 打开一个窗口，列出开发者在近期 LiquiGen 版本中所做的所有更改。

    • 3rd Party Licenses…： 打开一个窗口，列出用于开发 LiquiGen 的资源的许可证声明。

    • About…： 打开一个窗口，其中包含公司声明，以及 LiquiGen 功能的简要概述。

  1. 当前项目的文件名。 (Edited) 会在存在未保存更改时显示在文件名后面。打开默认预设时这里不会显示任何内容，但对其做出更改后，会显示 Untitled(Edited)。尝试保存未命名文件时，会弹出文件浏览器来设置文件名和位置。

  2. 显示项目备注。打开 Project Notes 窗口。只有在项目中添加备注时，此图标才会出现；可以在 Settings > Project Settings… > Notes 中完成。

  3. Update Available： 此按钮会在软件不是最新版本时显示。可以单击此按钮开始更新到最新版本。在弹出窗口中单击 Update，然后单击 Finish 来完成更新流程。

  4. ALPHA： 如果此标签出现在这里，表示软件仍处于非常早期版本，可能会有很多 bug 和缺失功能！

  5. 最小化 LiquiGen 窗口。

  6. 最大化 LiquiGen 窗口。

  7. 关闭 LiquiGen。

视口#

这里可以查看模拟、形状、力，或场景中的任何内容。

  1. 使用 拖动，可以通过此图标移动 4 个主要区块来重新排列 UI 布局。

  2. Scene 是默认选项卡，可在其中查看和操作所有内容。

  1. 可用摄像机的下拉菜单。在这里可以选择要透过哪台摄像机查看。

  2. 可在 Scene 选项卡中隐藏或显示的所有内容的下拉菜单。

    • Path tracing Ctrl + T 切换视口中的路径追踪模式；它是一种更真实的渲染方式，但会牺牲时间和性能。

    • Shapes H (19)

    • Liquid Mesh (15) 显示或隐藏视口中的液体。

    • Whitewater 显示或隐藏视口中的白水。（白水默认未启用，必须使用 Whitewater 节点设置）白水是由三种元素分开的粒子集合：

      • 16 Spray（飞溅）：表示水面周围的小型液体粒子。

      • 17 Foam（泡沫）：表示水面顶部的气泡。

      • 18 Bubbles（气泡）：表示液体内部的气泡。

    • Manipulator Switcher 这会显示 Move (9), Rotate (10) 和 Scale (11) 按钮。

    • Camera Gizmo (12) 活动摄像机视口方向的可视化表示。可以 单击圆点，将视图定向到该轴。也可以 单击并拖动球体来旋转视图。

    • Stats Shift + S (24) 关于模拟的统计信息，可用于管理计算和内存资源，或查找问题。带百分比的统计信息可帮助判断是否需要降低（看到较低百分比时）或提高（接近 100% 裁切时）分配的资源。

      • Time simulating： 求解器自上次重置模拟以来运行的时间。括号中的数字表示播放速度相对于步进率的倍率。例如，如果步进率为 60Hz，模拟以 60fps 运行，则该值为 1。步进率可在 Simulation 选项卡中，属于 Simulation 节点。

      • VRAM in use： 软件当前使用的 VRAM 数量，单位为 GB。高端显卡拥有更多 VRAM，可以运行更大的模拟。

      • Num particles： 场景中当前粒子数量。百分比表示相对于最大粒子数量的占比，最大粒子数可在 Resources 选项卡中，位于 Simulation 节点。

      • Num voxels： 场景中当前体素数量。百分比表示相对于最大体素数量的占比，最大体素数可在 Resources 选项卡中，位于 Simulation 节点中指定。有关体素的更多信息，请查看 体素 章节。

      • Liquid vertices： 液体网格中的当前顶点数。百分比表示相对于最大三角形数量两倍的占比。最大三角形数量可在 Resources 选项卡中，位于 Simulation 节点。

      • Liquid triangles： 液体网格中的当前三角形（多边形）数量。百分比表示相对于最大三角形数量的占比，最大三角形数量可在 Resources 选项卡中，位于 Simulation 节点。

      • Whitewater parts（白水粒子）： 场景中当前白水粒子（16、17、18）数量。百分比表示相对于最大粒子数量的占比，最大粒子数可在 Resources 选项卡中，位于 Whitewater 节点。

      • Projection Iters： 投影迭代次数。Projection 是一种改善体积守恒的算法；迭代次数表示该算法计算的次数，可提高模拟精度，但会增加模拟时间。百分比表示相对于最大迭代次数的占比，该最大值可使用 Projection: Max. Iterations 参数调整，该参数位于 Simulation 选项卡中，属于 Simulation 节点。

      • Max divergence（最大散度）： 当前时间步中任一体素内发现的最高 divergence（散度）值。散度指液体体积增加或减少，可能导致外观不正确或不稳定的模拟。Millivoxel 表示千分之一体素。因此，max divergence（最大散度）为 1 表示模拟中一个或多个含液体体素正在压缩到占据 99.9% 或 101.1% 的体素；max divergence（最大散度）为 1000 表示在给定时间步，一个或多个含液体体素被添加或移除（通常是后者）。可以通过降低 Projection: Target divergence（投影：目标散度） 并提高 Projection Max. iterations 参数调整，该参数位于 Simulation 选项卡中，属于 Simulation 节点。

  3. 切换诊断设置面板，在视口右侧添加或移除它。此面板可用于可视化模拟的各种方面。更多信息请查看 诊断 章节。

  4. 切换面板全屏。

  1. Sky： 这些设置由 Skybox 节点控制，文档见 此处！

  2. Ground： 这些设置由 Ground 节点控制，文档见 此处！

  1. Manipulator 可用于在视口中移动对象。有平移、旋转和缩放三种操纵器。可以使用左上角的操纵器切换器选择它们（9,10,11），除非它在 View 下拉菜单中被隐藏（6）。也可以按 Q 进行平移， W 进行旋转， E 进行缩放。如果某种操纵器类型无法选择，是因为所选对象不支持该操作。（例如旋转点光源）

  2. Force Gizmo 大多数力都有一个 Gizmo，可用浅蓝色箭头显示该力注入速度的方向。

  3. Inner Bound 所选力的内部边界。内部边界的蓝色透明区域表示力保持 100% 的区域。可以通过将 Falloff 参数设置为 None 以外的值来设置边界，该参数位于 Behavior 选项卡中。

  4. Outer Bound 所选力的外部边界。加深显示的区域表示过渡区域：力从内部的 100% 过渡到外部的 100% 减去 Falloff percent（因此默认外侧为 0%）。

  1. Preview 是用于预览将要导出内容的选项卡。

    1. View 下拉菜单，可切换统计信息的可见性。

    2. Image export nodes（图像导出节点）下拉菜单。在这里可以选择要预览的 Export: Image 节点。

    3. 渲染通道下拉菜单。在这里可以选择要预览的 Render Pass。

    4. No render pass mapping（无渲染通道映射）警告。看到这个图标表示 Export: Image 节点中没有设置 render pass mapping（渲染通道映射）。可以单击此图标自动创建一个。

    5. 放大或缩小。

    6. 缩放以适配整个选项卡。勾选后会禁用 5

    7. 切换渲染设置。它会显示或隐藏渲染设置 (13,14) Render Settings

    8. 将缩放（5）重置为 100%

    9. 切换裁剪 Gizmo。

    10. 在水平和垂直轴上裁剪。

    11. 垂直裁剪。

    12. 水平裁剪。

    13. 常规渲染设置

    14. Render pass 专用渲染设置。

  1. Export 是用于查看已导出的翻页序列或导出序列最后一帧的选项卡。导出通过 Export: Image 节点完成，文档见 此处

    1. Channels。 单击这些按钮中的任意一个可单独查看 Red（红）、Green（绿）、Blue（蓝）或 Alpha（透明度）通道；再次单击该通道可回到同时查看 Red（红）、Green（绿）和 Blue（蓝）。 Ctrl + 单击某个通道可将其加入通道选择或从中移除。

    2. 渲染通道。映射后的渲染通道下拉菜单，可选择要查看导出结果的渲染通道。

    3. Flipbook（翻页序列）。一种用于游戏的格式，所有帧都存储在一张图像中。只有在满足以下条件时才会看到它： Export Mode 位于 Export 选项卡中，属于 Export: Image 节点的设置，并被设置为 Flipbook。

    4. Export viewer。显示已导出的文件。

    5. Current Flipbook Frame（当前翻页序列帧），以细浅色边框标示。可以 单击任意帧，将其设为当前帧。

    6. Go To Start（转到开头）。将播放头设到时间轴开头。（Export 选项卡中的时间轴）

    7. 转到上一帧。

    8. 播放或暂停导出。

    9. 转到下一帧。

    10. Go To End（转到末尾）。将播放头设到时间轴末尾。

    11. Loop。切换导出播放到最后一帧时，是从开头重新播放，还是停止。

    12. Skip Frame。切换播放器是否在必要时跳帧，以跟上所选帧率。

    13. Current Frame。显示当前播放帧。也可以 在此框内单击以手动设置当前帧。

    14. Timeline（时间轴）。所有已导出帧编号的水平表示。

    15. Playhead。位于时间线上的当前帧位置。可以 单击并拖动播放头，在时间线上移动并查看不同帧。

    16. Frames Per Second。导出播放时使用的 FPS。数值越高，回放看起来越“加速”。可尝试设为目标帧率，例如制作电影时使用 24 fps。这样可以看到最终结果中的速度效果。

节点图#

这里用于管理创建模拟的构建块。可以把连线理解为数据，它们把设置中的一个部分连接到另一个部分。

  1. 使用 拖动，可以通过此图标移动 4 个主要区块来重新排列 UI 布局。

  2. 打开搜索框。 单击它会打开搜索框，可以输入节点名称或名称的一部分来快速选择该节点。

  3. 切换 Graph Tree（图树）。(9)

  4. 随机化所有已启用随机化的参数。这是快速获得效果变体的方法。有关随机化的更多信息，请查看我们的 随机化 页面！

  5. 将视图移动到节点中心。

  6. 将视图移动到已选节点中心。

  7. 将缩放重置为默认值。

  8. 切换面板全屏

  9. Graph Tree 在这里会以列表形式显示所有节点。可以使用 图标打开一个下拉菜单，显示连接到该节点输入引脚的节点。如果将鼠标悬停在节点名称上，可以单击 来选择节点。这样无需在节点图中搜索，就能快速选择节点并查看其参数！也可以使用 Shift + 多选节点。选中的节点会以 图标表示。

  10. Node（节点）。模拟的构建块。选中的节点带有蓝色边框。

  11. 输入引脚

  12. 连接线

  13. 输出引脚

  14. 切换节点是否启用。 Shift + 可对所有已选节点切换。

  15. Comment。用于整理节点、提升可读性的自定义命名节点容器。可以通过选择 Create Comment 来创建注释，该命令位于节点图的 菜单中；也可以按 Ctrl + G 有关注释的更多信息，请查看我们的 注释 章节！

  1. Note。可放置在节点图周围的自定义文本框，用于提供额外信息或辅助记忆。可以通过选择 Create Note 来创建备注，该命令位于节点图右键菜单中；也可以按 Ctrl + H 有关备注的更多信息，请查看我们的 备注 章节！

  2. Minimap。整个节点图的小型概览。可以在 Settings > Preferences… > General 部分启用和调整小地图。

  3. 节点会显示为按各自图标着色的块。选中的节点带有白色边框。

  4. 注释会显示为节点下方的矩形。注释颜色取决于它们在节点图中的颜色。

  5. 可见节点图区域。白色半透明框表示当前可见的节点图区域。放大节点图会让此框变小，缩小节点图会让它变大。要使用小地图移动可见区域，可以 单击跳转到所需区域，或 单击并拖动到该区域。

时间轴编辑器#

这里会从左到右显示时间。

有关如何使用此编辑器的说明，请查看我们的 时间轴编辑器 章节。

  1. 使用 拖动，可以通过此图标移动 4 个主要区块来重新排列 UI 布局。

  2. Snap keys to frames（将关键帧吸附到帧）。启用后（图标变蓝表示已启用），关键帧只能创建在整数帧编号上，也只能移动到整数帧编号。

  3. Fit view to all keys（适配所有关键帧）

  4. Fit view to selected keys（适配已选关键帧）

  5. 将垂直缩放重置为默认值，作用于 Curve Editor。Shift + 单击此图标可重置水平缩放。

  6. 切换面板全屏

  7. Reset R 将模拟重置到时间轴开头。

  8. 将播放头移动到上一个关键帧 Left

  9. 播放或暂停模拟 Space

  10. 将播放头移动到下一个关键帧 Right

  11. 移动到下一帧/模拟步 Z

  12. Toggle Loop L 启用循环后，时间轴编辑器中会以蓝色显示循环范围。可以通过 单击并拖动中间部分来移动这条蓝色条，也可以通过 单击并拖动边缘来缩放它。

  13. 切换时间轴以秒或帧显示。 Shift + F

  14. 时间轴滚动条。

  15. 可在这里搜索动画参数列表中的特定参数。

  16. Toggle Curve Editor（切换曲线编辑器） ` 有关如何使用此编辑器的说明，请查看我们的 曲线编辑器 章节。

  17. Toggle Timeline Autokey（切换时间轴自动关键帧） A 启用后，修改已启用关键帧动画的参数值时，会在播放头位置添加一个关键帧。

  18. Toggle Timeline Recording（切换时间轴录制） Shift + R 使用此按钮启动模拟时，所有对已启用 Timeline Override（时间轴覆盖） 的参数所做的更改都会实时转换为关键帧。

  19. Toggle Timeline Sync（切换时间轴同步） D 启用后，播放头始终与模拟时间位于同一位置。因此播放时蓝线和粉线不能分离。

  20. Toggle Follow Playhead（切换跟随播放头） F 启用后，时间轴会自动平移，使播放头始终保持在编辑器中央。

  21. Playhead 指示时间轴上的当前时间。

  22. 指示模拟当前所在时间。

  23. 帧编号。

  24. 带有启用关键帧动画参数的节点。可以使用 图标隐藏或显示动画参数。

  25. 启用或禁用该节点的关键帧动画。禁用后，该节点的参数不再随时间变化，但会保持关闭此按钮时的值。

  26. 隐藏或显示此节点所有参数在 Curve Editor 中的曲线。

  27. 指定曲线延续方式。将此参数的关键帧动画设为 Play Once, Loop（在末尾重新开始动画）或 Ping Pong（先正向播放动画，再反向播放，再正向播放，如此往复。）

  1. Parameter 可在这里设置当前帧的参数值。

  2. 启用或禁用该参数的关键帧动画。禁用后，该参数不再随时间变化，但会保持关闭此按钮时的值。

  3. 隐藏或显示此参数在 Curve Editor 中的曲线。

  4. Keyframe

属性面板#

  1. 使用 拖动，可以通过此图标移动 4 个主要区块来重新排列 UI 布局。

  2. Node Details（节点详情）： 此选项卡显示所选节点的所有参数。

  1. Favorites 此选项卡显示所有标记为收藏的参数。

    可以在 Node Details（节点详情）选项卡中，对任意参数勾选其旁边的星形图标 来完成此操作。

    Clear All 会从收藏列表中移除所有项目。所有星形图标都会取消勾选。

    在菜单栏的 Settings/Project Settings… 中，也可以根据默认值、上次保存状态或已加载的 .liquigen 文件自动收藏参数！

  1. Timeline： 此选项卡显示所有已启用关键帧动画的参数。

    Clear All 会从列表中移除所有项目。 注意，这会移除所有动画！

    参数上的关键帧动画通过将 override state（12）设置为 Timeline Override（时间轴覆盖）来启用。

    有关动画（时间轴）的更多信息，请查看我们的 关键帧动画 章节。

  1. Randomized： 此选项卡包含所有已启用随机化的参数；可按住 Shift + 单击 override state cycler（覆盖状态循环器）来启用（12)

    Randomize All 会为 Randomized 选项卡中的所有参数分配新的随机值。

    左侧的范围滑块定义随机值可选取的最小值和最大值。右侧紧邻的字段是参数值。 会随机化该参数（而不是全部参数）。更多信息请查看我们的 随机化 章节！

  2. 打开搜索框，用于查找所需参数，不受当前所在选项卡限制。可以使用 Ctrl + F 立即打开此功能！

  3. 仅显示带关键帧动画的参数，不受当前选项卡限制。这不同于 Timeline（时间轴）选项卡，因为它只显示所选节点的动画参数，而不是所有节点的。

  4. 打开下拉菜单，其中包含重置或随机化所选节点或选项卡所有参数的选项。

  5. 切换面板全屏

  6. Parameter tabs： 所有节点都有自己的参数选项卡集合，用易于查找的类别对参数进行排序。

  7. Parameter tab divider。它在列表中以视觉方式分隔某个选项卡的参数。可以使用 图标隐藏或取消隐藏该选项卡的参数。

  1. Parameter name： 将鼠标悬停在其上会显示该参数作用的说明。

  2. Checkbox： 可将参数设为开启或关闭。

  3. 重置为默认值。

  4. Mark as favorite： 这会让参数显示在 Favorites 选项卡中。

  5. Parameter special info： 将鼠标悬停在此图标上会显示参数对模拟影响的辅助信息。在 LiquiGen 中，此图标通常只出现在少数参数旁边，用于提醒用户修改该参数会重置模拟。

  6. Cycle Override State： 单击它会在该参数的不同 override state 之间循环。

    • No Override： 参数只由字段、复选框或下拉菜单中输入的值驱动。

    • Timeline Override： 参数由关键帧驱动，可以随时间变化。更多信息请查看我们的 关键帧动画 章节。

    • Pin Override： 参数由外部节点驱动，例如 oscillator。其值可基于函数随时间变化。更多信息请查看我们的 调制参数 章节。

    • Randomize Override： Shift + 单击。参数值可在 Randomized 选项卡中指定的范围内随机化。更多信息请查看我们的 随机化 章节。

  7. Value Slider： 可以 在此框内单击以输入所需值。也可以 单击并拖动来更改数值。还可以在这些文本框中使用数学表达式。例如输入 4*7/2+6-2 并按 Enter 会将参数值设为 18。这有助于快速将某个值相乘或减半等。

  1. 当通过手动输入设置了默认边界之外的参数值时，会出现此项。这样会把边界设为新的最小值或最大值。可以单击 图标打开 Set Parameter Bounds 窗口，在其中使用文本字段设置最小值或最大值；也可以单击 图标，将其重置为右侧显示的默认值；或使用 Reset Bounds 按钮同时重置两者。如果出现该图标 ，表示当前参数值超出最小或最大边界，重置该边界会导致该值被最小值或最大值覆盖。

参数边界会影响参数滑块、调制控件和时间轴控件的范围。

  1. 垂直滚动条。可用它滚动参数列表。

  2. 水平滚动条。

  3. 当前软件版本。
