颜色#

Color 是一类输出颜色值的节点。

Color Nodes（颜色节点）#

Color: Constant（常量颜色）#

输出单个颜色值。

你可以 单击彩色方块以打开 Color Picker。

Color Picker（颜色选择器）#

  1. Color picker（取色器）。按住 并拖动，可从屏幕任意位置选择颜色。这样甚至可以选择应用程序外部的颜色。

  2. 将颜色重置为该参数的默认值。

  3. 关闭颜色选择器。颜色会保持为颜色选择器中当前选中的颜色。你也可以点击颜色选择器外部来关闭它。

  4. Hue ring（色相环）。显示所有色相。选中的色相会用圆圈 7 你可以 在圆环上的任意位置单击或点击拖动以选择色相。

  5. Brightness and saturation triangle（亮度与饱和度三角）。三个角分别表示白色、黑色和完全饱和的颜色。选中的值会用圆圈 6 你可以 在三角形上的任意位置单击或点击拖动以选择颜色。

  1. Current Color（当前颜色）

  2. HEX code（HEX 代码）。你可以在这里输入十六进制代码来获得指定颜色，方法是 点击文本字段。

  3. RGB Mode（RGB 模式）。这会让滑块以 Red（红）、Green（绿）、Blue（蓝）数值表示颜色，全部映射到 0 到 255。

  4. HSV Mode（HSV 模式）。这会让滑块以 Hue（色相）、Saturation（饱和度）、Value（明度）表示颜色。 Hue 会从 0 到 360 度以环形方式映射，起点和终点都是红色；使用这个滑块时，可以看到色相环中的圆圈在转动。Saturation（饱和度）和 Value（明度）映射为 0% 到 100%；Saturation 从灰度映射到完全饱和，Value 从黑色映射到基于当前色相和饱和度的最亮颜色。

  5. Channel Values（通道值）。这些值表示旁边滑块的数值。 在文本框内单击即可手动输入数值。

  6. Channel Sliders（通道滑块）。这些滑块可用于修改颜色。滑块上的渐变表示如果指示器 14 位于该位置时选中颜色会是什么样。你可以 在滑块上的任意位置单击或点击拖动以选择颜色。

  1. Swatch Dropdown（色板下拉菜单）。

  • Saved Colors（已保存颜色） 包含已保存颜色的色板 16 可以使用 图标 18，用于保存所选颜色。也可以通过 右键单击其中一个并选择 Remove 17。

  • Recent Colors（最近颜色） 包含最近使用的 9 种颜色。关闭颜色选择器时，所选颜色会存为 Recent Colors 色板最右侧的最新颜色，其他颜色会依次向左移动一位，最左侧的颜色会被丢弃。

Color: Gradient（颜色渐变）#

  • Interpolation Color Space（插值颜色空间）： 一个下拉菜单，包含在颜色渐变中从一个点到另一个点插值颜色的不同方法。

  • Color Gradient： 创建一段颜色范围。

    • 通过 点击渐变来添加点。

    • 按住 并拖动可移动点。

    • 若要移除点，请使用 选中该点并按 Delete ，或通过 右键单击它并选择 Delete。

    • 若要编辑点的颜色，可以用 双击该点，或通过 右键单击它并选择 Change Color。

    • 可以使用 Color Picker，并用 在任意应用程序上点击并拖动，以从中取色来创建渐变。


可以通过 在颜色渐变上的任意位置右键单击来打开颜色渐变上下文菜单，其中包含以下选项：

  • Copy: 复制颜色渐变（所有点以及插值颜色空间）。

  • Paste: 粘贴颜色渐变。这会覆盖所有内容，并用复制的颜色渐变替换。

  • Reset: 将颜色渐变重置为由黑到白的两点颜色渐变。

  • Sort By Luminance: 根据亮度从暗到亮重新排列所有点。

  • Sort By Hue: 根据 0 到 360 度的色相重新排列所有点。

  • Sort by Saturation: 根据饱和度从低到高重新排列所有点。

  • Equally Distribute: 重新排列所有点，使它们在颜色渐变上均匀分布。

  • Shuffle: 随机重新排列所有点。每次使用该选项都会得到随机结果。

  • Reverse: 反向重新排列所有点，让最后一个点变为第一个，反之亦然。

  • Color Gradient Presets（颜色渐变预设）

点击带有 图标的按钮会打开渐变预设窗口。在这里，你可以组织、更新、导入和导出所有颜色渐变！

左侧区域是可包含渐变预设的类别或文件夹列表：

  • All 包含所有已保存的渐变预设。

  • Favorites 包含所有通过星标图标标记为收藏的预设。

  • Ungrouped 包含所有不在文件夹中的预设。如果预设被移动到此处，或在选择 All, Favorites或 Ungrouped 类别时添加，就会归入 Ungrouped。

  • Folders 可由用户创建，用于组织渐变预设。可使用 按钮（位于右下角）创建。如果选中了某个文件夹，新添加的预设会放入该文件夹。若要重命名或删除文件夹，可以 右键单击它并选择 Rename 或 Delete。也可以通过 点击并拖动它来移动文件夹位置。

右侧区域是颜色渐变预设列表：

  • 当前活动的预设会用 灰色圆点标记，位置在 图标旁边。

  • 该 图标可用于将渐变预设设为收藏或取消收藏。

  • 单击渐变预设会将它应用到颜色渐变参数。

  • Shift + 单击渐变预设会将它应用到颜色渐变参数，且不会关闭渐变预设窗口。

  • 你可以 点击并拖动渐变预设，将它移动到列表中的其他位置。

单击渐变预设时出现的上下文菜单包含以下选项：

  • Rename: 可为渐变预设输入新名称。

  • Favorite/ Unfavorite: 用于切换渐变预设是否为收藏。使用 图标也能完成同样操作。

  • Update: 用当前颜色渐变参数覆盖该渐变预设。

  • Move To…: 可将渐变预设放入指定文件夹。

  • Export…: 打开文件浏览器，将渐变保存为 JangaFX Color Gradient (.jfxcg) 文件到指定位置 （请注意，Interpolation Color Space（插值颜色空间）也会保存在预设中），或保存为 .png 文件。该文件可加载到大多数软件中，例如作为另一个着色器的颜色输入。图像分辨率为 512 x 12 像素，意味着可以存储 512 种不同颜色。

  • Delete: 完全移除渐变预设。此操作无法撤销！

顶部的 搜索功能可根据名称搜索渐变预设。它始终会搜索所有预设，无论它们属于哪个文件夹。

窗口底部还有几个选项：

  • 将当前颜色渐变参数添加为渐变预设，并立即进入重命名模式，以便为新渐变预设命名。

  • 向渐变预设窗口添加新文件夹，并立即进入重命名模式，以便为新文件夹命名。

  • 打开文件浏览器，你可以选择 JangaFX Color Gradient (.jfxcg) 文件，将其作为渐变预设添加到渐变预设窗口。 EmberGen Color Gradient (.embercg) 文件是旧格式，但也可以为了向后兼容而导入。

Color Selector（颜色选择器节点）#

基于渐变上的指定位置，从 Color Gradient 节点输出单个颜色。

连接颜色节点#

颜色节点可以连接到颜色参数。

该参数的颜色随后会由颜色节点控制。

颜色参数可以通过其旁边的彩色方块来识别。
