欢迎#

欢迎来到 JangaFX 官方文档站点！在这里，你可以找到相关资源与指南，帮助你充分发挥我们的工具能力并提升使用体验。

探索#

EmberGen#

EmberGen 是一款实时体积流体模拟工具，可以即时模拟、渲染并导出翻页序列、图像序列和 VDB 体积。借助 EmberGen，你可以创作从火焰、烟雾到爆炸和魔法缕状烟雾等各类效果。EmberGen 让你能够以毫秒级速度迭代模拟，而不是耗费数小时等待。

从这里开始学习使用 EmberGen： EmberGen 文档

LiquiGen#

LiquiGen 是我们在实时液体模拟方面的最新重大创新。你可以轻松生成翻页序列、图像序列和 Alembic 缓存，并以精确控制来模拟泡沫、飞溅和气泡。

从这里开始学习使用 LiquiGen： LiquiGen 文档

IlluGen#

IlluGen 是专为实时视觉特效和技术美术资产生成而构建的工具。它是一款基于程序化节点的工具，可帮助你生成 2D 与 3D 资产。平铺噪声、法线贴图、流向贴图、3D FX 网格、焦散、遮罩、扭曲等资产都可以在这里轻松生成。凭借完整的动画时间轴、翻页序列打包与解包、便捷的 Alpha 通道等能力，IlluGen 将成为实时 VFX 艺术家的重要工具。

从这里开始学习使用 IlluGen： IlluGen 文档

GeoGen#

GeoGen 重新诠释了地形与星球生成的可能性。面对众多优秀的同类工具，我们知道必须把它提升到新的层级。凭借现代化的节点式工作流、独特的模拟能力，以及面向游戏制作的流程增强，GeoGen 将成为你工具箱中的强大工具。

从这里开始学习使用 GeoGen： GeoGen 文档
